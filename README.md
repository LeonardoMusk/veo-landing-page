# VEO Landing Page

Landing oficial de VEO, desarrollada con Next.js y preparada para su
publicación en Vercel.

## Desarrollo local

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`.

## Producción

```bash
npm run build
npm start
```

El formulario de contacto utiliza Formspree.
